# AI Smart Study Planner & Timetable Scheduler

A lightweight, open-source web application designed to help a friend stress less about upcoming exams by automatically organizing their study topics, calculating deadlines, and prioritizing what to study first using structured heuristics based on open-source AI workflows.

## Features
- **Smart Priority Sorting:** Detects difficult subjects and automatically highlights them as critical focal points.
- **Dynamic Countdown:** Calculates exactly how many days are left until the exam date.
- **Structured Daily Timetable:** Provides morning, afternoon, and evening routine blocks optimized for retention.

## Built With
- **Frontend Architecture:** HTML5, CSS3, and JavaScript (Vanilla ES6).
- **AI Core:** Designed leveraging local prompt workflows and structural rule-based zero-shot classification logic aligned with open-weight model architectures.

## Built For A Friend
This application was created for the Hacktoberfest 2026 Launch Weekend DEV Challenge to help a friend structure their chaotic exam preparation schedule into an actionable, priority-driven daily routine.
